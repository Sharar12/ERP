# Universal ERP - Technical Documentation

## Overview
This directory contains architectural specifications, API documentation, database schemas, and developer guides for the Universal ERP platform.

### Structure
- `DOCS for Project Plan/`: High-level business and technical roadmaps (`Project Plan.txt`, `ToDo List.txt`).
- `docs/`: Ongoing technical specifications, API contracts, and architecture guides.
- `deployment/`: Production and staging deployment guides, Dockerfiles, and CI/CD configurations.
